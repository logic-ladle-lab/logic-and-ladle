## 2. キャプション（コピペ用）

```
切ったアボカドやリンゴが黒くなるのは「古いから」ではありません。
植物が持つ酵素 PPO による“自己防衛反応”です。🥑🍎

黒くなる条件は【フェノール＋酸素＋酵素】の3つ。
このどれか1つを断てば、変色は止まります👇

🍋 酸（レモン・酢）→ pHを下げて酵素を停止。アボカドに最適
🧂 塩水 → 酵素を阻害（1%程度・しょっぱさに注意）
💊 ビタミンC → 酸化を巻き戻すプロの解。味を変えない
🫙 真空パック → 酸素を物理的に遮断（最強）

詳しい仕組みは記事で解説しています（Exp.11）。
プロフィールのリンクからどうぞ🔗
```
